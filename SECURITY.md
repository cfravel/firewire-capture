# Security Policy

## Supported Versions

Security fixes are applied to the current code and current Windows 11 and
Windows XP SP2 builds. Older snapshots and locally modified builds may not
contain the latest fixes.

| Product | Security support |
| ------- | ---------------- |
| Current `fwcap.exe` for Windows 11 | Yes |
| Current `fwcap-xp.exe` for Windows XP SP2 | Yes |
| Older builds and snapshots | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public GitHub Issue.

Use GitHub's private vulnerability-reporting feature for this repository.

Include, if possible:

- the affected version or commit;
- executable name and Windows version;
- whether the GUI or command-line interface was used;
- reproduction steps;
- expected and observed behavior;
- any relevant logs or screenshots.

I will review reports as promptly as practical.
